El Patrón de Diseño de Django

Django implementa una variación del patrón clásico MVC (Modelo-Vista-Controlador) denominada MVT. En este esquema, el propio framework actúa como el Controlador, mapeando las URLs del usuario hacia vistas específicas que interactúan con la base de datos (Modelo) y devuelven el resultado formateado (Template).
